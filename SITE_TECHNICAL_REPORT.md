## Что не завершено — специально

1. Утвердить достоверные юридические реквизиты и адрес оператора (ИП Вертинская Анна Ивановна).
2. Оформить и разместить политику обработки персональных данных и отдельное согласие, проверить требования закона и настройки Яндекс Формы.
3. После этого повторить тест и включить автоматическую форму на главной.
4. Подключить собственный домен и настроить Яндекс Вебмастер / Google Search Console. Сейчас GitHub Pages уже обеспечивает хостинг сайта.
5. Войти в Pages CMS через GitHub для первого теста редактирования — пользователь решил отложить.

**Вымышленный адрес в `legal-drafts/` является примером оформления, а не адресом оператора.** Он не используется на открытых страницах сайта.

Реализация статических файлов готова к дальнейшей публикации контента. Коммерческий приём заявок нельзя считать запущенным до завершения указанных условий.

# Админ-панель для сайта «Всероссийский центр»

Используется **Pages CMS**, внешняя система редактирования статического сайта через GitHub.

## Вход
1. Откройте https://app.pagescms.org/ (или локальную инструкцию https://sirotaandre07-cell.github.io/stroyanalitika/admin.html).
2. Выберите вход через GitHub владельца `sirotaandre07-cell`.
3. Если появится экран разрешений GitHub App, **ограничьте доступ одним репозиторием** `sirotaandre07-cell/stroyanalitika`.
4. Откройте репозиторий и ветку `main` (конфигурация `.pages.yml` уже добавлена).

## Что изменяется без кода
- **Тексты, контакты и фотография** (данные в `content/site.json`): текст «О центре», вводные тексты раздела «Контакты», email, подпись к email, ФИО ИП в контактах, картинка в шапке.
- **Статьи и новости** (данные в `content/news.json`): записи массива, заголовки, даты, тексты, изображения и переключатель публикации. Код статьи `id` уникальный; не менять его после публикации ссылки на статью.
- Файлы изображений сохраняются в `assets/`.

Сайт отображает данные `content/*.json` через JavaScript. Если данные временно недоступны, главная остаётся с запасными статическими текстами; новости показывают уведомление о недоступности.

## Важные ограничения
- Это не отдельный защищённый портал на домене сайта; авторизация происходит в Pages CMS через GitHub. `admin.html` — **только инструкция и ссылка**, а не форма логина.
- Страница GitHub Pages и репозиторий публичные. **Не помещайте туда пароли, персональные данные клиентов, паспортные сведения, приватные документы и ключи API.**
- Изменение email в `content/site.json` обновляет адрес в разделе «Контакты» и подсказках ручной заявки, **но не** получателя уведомлений в Яндекс Формах и не правовые документы. Получателя нужно отдельно изменить в конструкторе Яндекс Формы.
- Реквизиты ИП: в CMS пока редактируется только ФИО в блоке контактов. Политика обработки данных и согласие — отдельные юридические документы, находятся в `legal-drafts/` и не публикуются до утверждения.
- Новые материалы в `content/news.json` отображаются через JS после загрузки; список по годам не генерирует уникальные SEO-страницы — для поискового продвижения каждой статьи потребуется отдельная страница и автоматическая сборка.
- Любой, кто получил **доступ на запись** к репозиторию, может менять опубликованный сайт. Контролируйте разрешения GitHub App и включите двухфакторную защиту аккаунта.
- Публичная ссылка `admin.html` не предоставляет дополнительных прав: все изменения разрешены только владельцам репозитория через GitHub.

# ВЦОС — режим «Скоро открытие»

Дата включения: 29 октября 2026 года.

## Как устроено

На главной и остальных HTML-страницах сайта временно отображается заставка «Скоро открытие» с золотым знаком ВЦОС.
Режим использует общий файл `assets/coming-soon.css`: он скрывает рабочие элементы сайта и отображает статичный блок `#vcos-prelaunch-screen`.
Основной сайт, тексты, изображения, CMS-конфигурация и интеграция Яндекс Формы сохранены, ничто не удалено.

Точка восстановления **до установки заставки** — ветка
`full-site-before-opening-2026-10-29` (коммит `aef8e3be2a925df1fd87e464fe4f62da5220cbdc`).

## Что доступно посетителю

- Логотип ВЦОС и сообщение «Скоро открытие».
- Ни рабочие формы, ни остальные разделы визуально не отображаются.
- На HTML-страницы временно добавлен `robots=noindex,nofollow`, а в sitemap.xml нет обычных URL.

**Ограничение:** это не система авторизации. Данные и исходники остаются доступны через публичный GitHub-репозиторий, HTML страницы / просмотр кода, а статические материалы могут быть доступны по прямым ссылкам. Нельзя хранить на GitHub Pages секреты, персональные данные клиентов или закрытые документы.

## Как открыть сайт позднее

1. Заменить содержимое `assets/coming-soon.css` на:
   `#vcos-prelaunch-screen { display:none!important; }`
2. Удалить временный метатег `<meta name="robots" content="noindex,nofollow">` со всех основных страниц (`index.html`, `services.html`, `materials.html`, `news.html`; у админ-страницы и тестовых страниц метатег noindex оставить).
3. Вернуть список индексируемых страниц в `sitemap.xml` (главная, услуги, материалы, новости) с адресом `https://xn--b1ayjs.xn--p1ai/`.
4. Проверить работу HTTPS, GitHub Pages custom domain `xn--b1ayjs.xn--p1ai`, изображения, навигацию, мобильное отображение и редактор Pages CMS.
5. Согласовать реальный адрес и реквизиты ИП, политику обработки персональных данных, отдельное согласие и настройки Яндекс Формы; только после этого разрешить реальную подачу заявок с персональными данными.

До готовности к запуску не включать `yandexFormEnabled` в `config/scan-form.js`.

## DNS и домен

Custom domain в `CNAME` оставлен без изменений.
В Рег.ру пользователь настроил четыре A-записи на IP GitHub Pages и CNAME для www.
До подтверждения HTTPS новый адрес может открываться не сразу.
